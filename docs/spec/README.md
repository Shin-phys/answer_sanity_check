## 第1版の実装メモ

仕様書どおりに実装しています。仕様書から変えた点・補った点は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 増減チェックの追加 | レベル3の不合格問題が少なかったため、S03・S05・S07・S08・S12・S14 に増減の検算を追加した（追加分も、正しい式が合格することをテストで確認） |
| レベル2・3に出す式 | 単位の合う式だけを出す（1問で見る観点を1つにするため）。単位の合わない式はレベル1と4で使う |
| 問題のくり返し | 直近6問と同じ問題はできるだけ出さない |
| 極限の近づけ方 | 0へは 10⁻⁶・10⁻⁸、無限大へは 10⁶・10⁸ の2段階（平方根を含む式でも判定が安定するよう、仕様書の 10⁻³・10⁻⁴ より小さくした） |
| 極限の合格条件 | 期待値との差が、期待値（または式の代表的な大きさ）の 0.1% 以内 |
| レベル4の検算ボタン | 検算を選ぶと、各式の結果（単位／そのときの値／増減）を式の右に表示する |
| レベル5 | 収録は4問。1セット＝4問 |
| キーボード | PC・投影用に、← → キーでも答えられる |
