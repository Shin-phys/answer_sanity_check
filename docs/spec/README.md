## 第1版の実装メモ

仕様書から変えた点・補った点は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| レベル2・3の形式（2026-11-17 変更） | 仕様書では「誤りを含む式＋検算の文→合格／不合格」だったが、表示された式が現象と合わず混乱するため、「**正しい式**＋極限・増減についての説明→その通り／誤っている」に変更した。誤った式が出るのはレベル1（「ある人が出した答え」と明示）・4・5だけ |
| 説明の正誤の決め方 | 極限は、正しい式がとる値 `expect` と、誤った説明に使う値 `alts` をデータに持ち、正誤は正しい式の数値計算から決める。増減は「大きい／小さい／変わらない」の3つの説明のうち、正しい式の動きと一致するものだけを正とする |
| 検算の追加 | 極限を3つ（S13 の M=m、S15 の m₁=m₂、S18 の v→V）、増減を多数追加（質量によらないことを問う「変わらない」が正解の説明を含む）。計：極限29、増減35 |
| 正しい式の確認 | 20の正しい式が基本法則（運動方程式・保存則など）を満たすことを `physics.test.ts` で数値確認する |
| 問題のくり返し | 直近6問と同じ問題はできるだけ出さない |
| 極限の近づけ方 | 0へは 10⁻⁶・10⁻⁸、無限大へは 10⁶・10⁸ の2段階（平方根を含む式でも判定が安定するよう、仕様書の 10⁻³・10⁻⁴ より小さくした） |
| 極限の合格条件 | 期待値との差が、期待値（または式の代表的な大きさ）の 0.1% 以内 |
| レベル4の検算ボタン | 検算を選ぶと、各式の結果（単位／そのときの値／増減）を式の右に表示する |
| レベル5 | 収録は4問。1セット＝4問 |
| キーボード（2026-11-17 追加） | PCではキーボードだけで全画面を操作できる。キーの一覧はリポジトリの README を参照。キーの案内は、マウスのある端末でだけボタン上に表示する |
